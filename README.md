# Portafolio de Fernando Olivares Cerda

Este repositorio está preparado para publicarse con GitHub Pages.

## Publicación rápida desde la web

1. Crea en GitHub un repositorio público llamado `fdol212.github.io`.
2. Sube el archivo `index.html` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda los cambios.
7. La página quedará disponible en:
   `https://fdol212.github.io`

## Edición

Todo el diseño está contenido dentro de `index.html`, por lo que puedes modificar textos,
colores y secciones desde el editor web de GitHub sin instalar nada.

## Recomendación

Para una primera versión del portafolio, la vía web es la más simple. Más adelante conviene
usar Git desde tu computador si quieres mantener versiones, trabajar con ramas o agregar
más proyectos.
